## Purpose

Глобальный sh-хук: безусловный вызов заданного при старте скрипта на каждое событие любой стратегии, с событием в виде одного JSON на stdin.

## ADDED Requirements

### Requirement: Настройка хука при старте
Сервер SHALL принимать путь к скрипту через ключ запуска --hook. Если хук не задан — события стратегий SHALL логироваться без запуска внешних процессов.

#### Scenario: Хук не задан
- **WHEN** сервер запущен без --hook и происходит событие стратегии
- **THEN** событие фиксируется в логе, внешний процесс не запускается

### Requirement: Безусловный вызов на каждое событие
На каждое событие каждой стратегии сервер SHALL запускать скрипт ровно один раз. В stdin скрипта SHALL передаваться один JSON-объект: ts, strategy_id, account_id, env, type, rule_index и trigger (для rule_matched), results (результаты действий). Типы событий: strategy_started, rule_matched, strategy_updated, strategy_cancelled, strategy_finished. Событие strategy_cancelled SHALL включать результаты очистки заявок и закрытия позиций.

#### Scenario: Передача события в скрипт
- **WHEN** сработало правило стратегии
- **THEN** скрипт запускается и получает в stdin JSON с type=rule_matched, trigger и results

#### Scenario: Событие очистки
- **WHEN** cancel_strategy завершает очистку
- **THEN** скрипт получает событие type=strategy_cancelled с результатами отмен и закрытий

### Requirement: Асинхронный запуск
Запуск скрипта SHALL выполняться асинхронно в фоне и NOT блокировать движок стратегии. Очередь и гарантии порядка не предусмотрены: на каждое событие запускается отдельный процесс, даже если предыдущий ещё выполняется.

#### Scenario: Независимые запуски
- **WHEN** два события происходят подряд до завершения первого скрипта
- **THEN** оба скрипта выполняются независимо, движок не блокируется

### Requirement: Устойчивость к отказам
Любое завершение скрипта (код выхода, сигнал, ошибка) SHALL NOT влиять на работу стратегии; stderr скрипта SHALL логироваться. Таймауты не применяются: скрипт выполняется без ограничения времени.

#### Scenario: Ошибка скрипта
- **WHEN** скрипт завершается с ненулевым кодом или по сигналу
- **THEN** ошибка логируется, движок стратегии продолжает работу

### Requirement: Переменные окружения
Сервер SHALL устанавливать для скрипта переменные окружения YATIS_STRATEGY_ID (идентификатор стратегии) и YATIS_EVENT_TYPE (тип события).

#### Scenario: Контекст в окружении
- **WHEN** скрипт запускается на событие
- **THEN** в его окружении присутствуют YATIS_STRATEGY_ID и YATIS_EVENT_TYPE
